## 2　填表格式

一行一条，字段与 CSV 表头一致。多选轴用英文分号分隔，首个为主：

```
E0002-1 | a: A2;A5 | b: B1 | c: C6 | d: D3 | e: E1 | f: F2;F3 | off_axis: 无 | confidence: high | 证据句: "楼梯间被浓烟封死，无法下行" | 判定说明: 全篇写住户自行发现并判断，路径归零后固守
```

三条硬约束（与 Codebook 一致）：

1. 每个非「未报告」的档位，必须能摘出一句**逐字**原句（≤30 字）。摘不出，退回「未报告」。
2. `off_axis` 只在这条**不含任何当事人火灾过程**时填「有」。
3. `confidence` 只有两档。满足任一条即 low：①六轴所需信息缺失过半；②主体指代含混；③同一段文字可支持两个互斥档位。

---

## 3　三个最容易犯的错

| 错 | 表现 | 正确做法 |
|---|---|---|
| 用常识补 | 「38 层肯定很难逃」「高层一定用楼梯」，于是标了 c 轴 | 正文没写就是未报告。高层这个事实本身不是 c 轴证据 |
| 主体混 | 把记者看到的、消防员做的、邻居说的，算成当事人的经历 | d1–d5 只记被编码当事人本人。救援者的动作记在 e／f 或 off_axis |
| 档位贪多 | 一条把所有相关的档都标上 | 首个是主档。多标会让共现矩阵失去区分度，只在正文明确支持时才加第二档 |

## 4　编完之后

```bash
cd repo/00_核心交付
python 08_人工抽检_一致性计算.py
```

输出逐轴人机一致率。判读门槛：

| 一致率 | 处置 |
|---|---|
| ≥ 85% | 该轴可由模型单独承担，写「经 12 条人工抽检，一致率 xx%」 |
| 70–85% | 模型作初标，人工复核全部低置信条目 |
| < 70% | 该轴判定线重写，本轮 12 条作废重抽 |

比百分比更有用的是**逐条看分歧归因**：分歧是「人的判定更对」（说明 codebook 措辞误导）还是「参考标注更对」（说明漏读了某句）。前者改 codebook，后者不改。这一句要写进论文的方法章。
