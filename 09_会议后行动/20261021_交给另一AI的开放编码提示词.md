# 给另一 AI 的开放编码任务

你是研究者的第二编码者。请对 20 条高层火灾新闻做结构化开放编码，用于检查 VR 共情叙事 Design Space v2 是否遗漏“信息到行动”的机制。

## 输入文件

1. 正式候选池：`06_工作流产物/第10轮_WB高层筛选/recommended_open_coding_pool.csv`
2. 人工细节提取：`06_工作流产物/同步包_20261021/recommended_id_chinese_body.xlsx`
3. 候选 codebook：`03_设计空间/Design_Space_v2.1_候选开放编码codebook.md`
4. 背景参考（只用于理解旧标签，不得覆盖正文证据）：`06_工作流产物/同步包_20261021/Design Space (1).md`

## 任务边界

- 只编码 20 条正式候选池记录；不要编码全集分类表、排除表或待核验表。
- 以正文为主要证据；人工细节提取表是线索和补充，不是自动正确答案。
- 不把旧人工标签直接搬过来；旧标签只用于最后比较。
- 不把“新闻没有提到”标成“没有发生”。
- 不推断听障、视障、轮椅、心理状态、动机或建筑结构。
- 不把视频、照片或社交媒体线索当成已核验事实；如果正文只说有视频，标记为“视频线索待核验”。
- 气味、烟、声音等只按正文记录；不要自动把气味变成硬件方案。

## 每条记录必须回答

1. 核心事实是什么？
2. 危险信息从哪里出现？
3. 信息处于什么状态：未察觉、模糊线索、已察觉未确认、已确认、被通知、冲突或未报告？
4. 人物是否误解、迟疑，或信息不足以支持行动？
5. 行动链如何展开：发现→确认→移动/留守→受阻→求助/互助→结果？
6. 行动链在哪里中断？
7. 哪些空间在当时可通行，哪些不可通行，是否随火势/烟雾/门/救援状态改变？
8. 谁向谁传递信息或提供行动支持？
9. 现有 v2 标签无法表达什么？
10. 证据原句是什么？

## 输出一：逐条 JSONL

每条记录一行，保存为 `open_coding_ai_v21.jsonl`。严格使用以下结构：

```json
{
  "record_id": "",
  "core_fact": "",
  "information_source": [],
  "information_state": "",
  "information_interpretation": "",
  "information_confirmation_path": "",
  "action_chain": [],
  "action_breakpoint": [],
  "spatial_affordance": [],
  "social_mediation": [],
  "body_context": [],
  "sensory_cue": [],
  "candidate_mechanisms": [
    {"concept": "", "evidence_refs": ["Q1"]}
  ],
  "evidence_quotes": [
    {"id": "Q1", "quote": "", "location": "中文正文/人工提取第几列或段落"}
  ],
  "uncertainty": [],
  "needs_human_review": false,
  "review_reason": ""
}
```

## 输出二：候选概念审查表

保存为 `codebook_review.csv`，每行一个候选概念：

`concept,frequency_20,record_ids,distinct_from_v2,design_implication,keep_as_candidate,reason`

至少审查：`cue_to_confirmation`、`interpretation_gap`、`action_sufficiency`、`action_chain_break`、`dynamic_action_space`、`social_information_mediation`、`social_action_scaffolding`、`ambiguous_early_cue`、`state_dependent_affordance`、`multimodal_substitution`。

## 输出三：分歧和疑问

保存为 `open_coding_ai_v21_review.md`，只列：

- 证据不足但容易误标的记录；
- 与 v2 标签边界不清的概念；
- 人工细节提取与正文冲突的地方；
- 需要研究者裁决的项目；
- 你建议保留、合并或删除的候选概念及理由。

## 判断标准

你不是在判断一篇新闻“是否适合做 VR”，而是在描述新闻中哪些信息、空间、身体和社会关系影响了行动。先写证据，再写分析。若无法从正文支持，就填“未报告”或加入 `needs_human_review`，不要用常识补全。
