# 人工标注目的与开放编码流程

## 1. 人工打标到底要回答什么

人工标注有三个目的：

1. **把新闻中的叙事细节变成可分析证据**：例如“听不到警报”“被困在阳台”“邻居敲门”“轮椅无法下楼”。
2. **检查已有设计空间是否有材料基础**：一个维度如果很少出现，不能直接作为核心设计维度；一个维度在不同事件中反复出现，才有资格进入设计空间。
3. **发现已有设计空间遗漏的变量**：特别是现有标签无法准确描述、但会影响 VR 叙事或交互的细节。

标签不是新闻摘要，也不是“这篇文章适不适合做 VR”的主观评分。每个标签都应能回答：正文中出现了什么证据？这个证据可能转译成什么叙事、交互或反馈？

## 2. 你之前有设计空间再打标，应该怎么处理

之前的标注仍然有价值，但它主要承担“验证已有维度”的功能。它不能单独证明设计空间是新的，因为当时的标签已经规定了你能看到什么。

因此采用两层流程：

### 第一层：开放编码（发现）

从现有主保留集和新补搜候选中抽取一小批材料，暂时不强迫自己使用旧标签。逐篇记录：

- 谁在什么位置；
- 缺少或误解了什么信息；
- 身体或感官遇到什么限制；
- 哪个建筑或社会关系造成阻碍；
- 做了什么动作，动作结果是什么；
- 报道用了什么叙事方式让读者理解处境；
- 旧编码表无法表达的细节是什么。

建议先由你独立开放编码约 20–30 条，再让第二位编码者对其中 10 条独立开放编码。此阶段不急着计算正式一致性，重点是收集候选概念和分歧。

### 第二层：结构化编码（验证）

把开放编码中反复出现、定义清楚、能转成设计变量的概念加入或修订 codebook。然后冻结版本，进行两人独立正式标注，并计算一致性。

这样既不会被旧设计空间限制，也不会把偶然出现的新闻细节直接宣布为新维度。

## 3. 什么时候算“新的设计空间维度”

一个候选维度至少要满足四个条件：

1. **材料重复出现**：不只来自一篇特殊报道；
2. **概念边界清楚**：能和已有维度区分；
3. **可转译为设计选择**：会改变视角、信息通道、空间安排、行动反馈或叙事结构；
4. **能产生可观察后果**：用户的理解、判断、行动或体验可能因此改变。

例如，“听不到警报”本身是感知通道限制；如果材料进一步显示“只能通过邻居敲门确认火灾”，那么“社会中介的信息获得”可能是一个候选新维度。它只有在多条材料中反复出现，并且会改变 NPC、信息延迟和行动选择时，才值得升级为设计维度。

## 4. 打标时最需要注意的事

- **证据和推断分开**：正文写“老人等待邻居救援”是证据；写“老人缺乏自主行动能力”是分析推断，需放在分析备注，不要伪装成原文事实。
- **没有提到就不要补标签**：新闻没写听障，不能因为场景适合听障 VR 就标成听障。
- **区分缺失和否定**：没有写到视觉警报，不等于现场没有视觉警报；只能标“未报告”。
- **记录动作序列**：发现、确认、移动、受阻、求助、获救/等待，比单纯标“困难”更有设计价值。
- **记录信息来源**：声音、灯光、手机、邻居、消防员、广播、手势等来源要区分，因为它们对应不同交互机制。
- **不要把情绪词当作处境机制**：“害怕”“绝望”是情绪结果；“因为看不到出口指示而返回房间”才是可设计的机制证据。
- **允许多选，但每一项都要有证据句**：多选不能变成“可能都有关”。
- **保留不确定性**：设置“未报告”“证据不足”“需裁决”，不要为了完成表格硬选。
- **分歧要留下来**：分歧日志本身能显示哪些概念定义不清，并帮助修订 codebook。

## 5. 推荐的标注记录格式

每条新闻至少保留以下五列：

| 字段 | 填写内容 |
|---|---|
| 原文证据 | 直接摘录或准确定位的句子/段落 |
| 事实标签 | 正文明确写出的身体、感知、空间、行动信息 |
| 分析标签 | 对设计空间可能有意义的概念 |
| 设计转译 | 可转成什么 VR 变量或反馈 |
| 不确定性/分歧 | 缺失信息、替代解释、与另一编码者的差异 |

## 6. 你现在最适合的工作方式

先不要重新大规模搜集一批完全不同的数据。建议：

1. 用现有 124 条主保留集中的 20–30 条做开放编码；
2. 同时加入我补搜的候选中已核验的高价值条目；
3. 将开放编码结果和现有设计空间逐项对照，标记“已有维度、需要拆分、候选新维度”；
4. 再决定是否进行第二轮精准补搜；
5. 设计空间版本冻结后，再做 100–140 条正式双人标注。

这样新设计空间来自“旧语料的新分析 + 针对缺口的补搜”，而不是先盲目收集大量新闻。
