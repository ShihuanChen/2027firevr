# GPT 独立审查提示词（CHI 2027 VR 高层火灾共情系统 · 新闻语料筛选方法）

## 一、项目背景（请先完整阅读）

我们正在撰写一篇 CHI 2027 论文，主题是 **VR 高层火灾共情系统**：重建香港宏福苑等真实高层火灾现场，让用户以六类残障身份（听障/老年/轮椅/管状视野视障/儿童/拄拐）第一人称体验逃生困境。系统设计部分不是本次审查重点，**本次审查聚焦"新闻语料筛选方法"（论文第 4-5 章）**——即我们如何从海量新闻中筛选出可被 VR 重建的火灾报道。

**核心方法学逻辑（人机协同三阶段）**：
1. **阶段一 · 规则归纳（人工先行）**：从 8,180 条检索结果抽样，人工判定约 403 条（GoldSet103 顺序样本 + 分层抽样 v2/v3/v4 + 批次 001/002），约 92% 判剔除 → 归纳出保留标准（I1 具身场景细节 / I2 人物叙事）与排除标准（E1-E6），并形成负样本。
2. **阶段二 · AI 大规模执行**：Grok 读正文语义判火灾（K=1,443 真火灾 / D=5,192 非火灾 / E=31 错误，误留率 0%），同事件去重后得到 1,027 篇候选池。
3. **阶段三 · 精判定稿（人工复核）**：在 1,027 候选池上按 I1/I2 二元标准逐批判定（第 1-2 批 300 条 → 精简 101 → 超精简 78 → 边缘补判 50 → 第 8 轮 24），每批用新判定回注重校准，人工精判 291 条，保留 109 条；另有 16 篇人工补充高价值报道（幸存者自述/证词，不参与漏斗）。

**关键数字与口径（已统一，请以此为准）**：
- 漏斗（6 个剩余数）：8,180 检索 → 6,666 正文有效 → 1,443 AI 判火灾 → 1,027 去重 → 109 人工精判保留 →（+16 篇补充 = 素材库）
- 694 = 人工判定累计工作量（403 规则归纳 + 291 火灾池精判），**只在 4.2 节作为"累计工作量、不参与漏斗"出现一次**
- 保留率 1.64% = 109/6,666（PRISMA 1-4% 正常区间）
- 六维打标（109+16 篇）：S 空间 93% / A 声音 70% / V 视觉 95% / T 时间 88% / B 身体 88% / C 社交 98%
- 六角色素材支撑（实测）：老年 51、儿童 42、听障 18、视障 18、轮椅 1（5636 补标后）、拄拐 0
