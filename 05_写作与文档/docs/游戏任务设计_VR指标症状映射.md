## 1. 设计哲学：从"新闻→VR指标"到"VR指标→症状体验"

```
新闻语料提取            场景重建参数              玩家体验＝障碍症状
───────────────────  ─────────────────────  ──────────────────────
"黑烟从门缝涌入"   →  烟雾密度=0.7-0.95   →  视障者：可见距离从3m→0.5m
"火警铃响了但没人醒" →  音频警报85dB       →  听障者：警报完全听不到（信息断裂）
"老人扶着墙慢慢走"   →  步速=0.4m/s        →  老年人：每3层必须停下来喘气
"轮椅卡在楼梯口"     →  楼梯碰撞体积锁死   →  轮椅者：唯一出口被物理阻断
"外面全是浓烟看不清"  →  能见度<3m         →  全盲：本就全黑，可闻变可贵
```

**核心原则**：VR环境参数是"因"，障碍症状是"果"。同一个环境参数在不同障碍模块下产生不同的主观体验——这就是共情的来源。

## 2. VR环境指标 → 障碍症状映射表

### 2.1 映射总表

| VR环境指标 | 来源(新闻命中) | 健全人体验 | 老年人(M+S) | 听障者(A) | 视障-管状(V) | 轮椅者(M) | 儿童(M+低视角) |
|:---|:---:|:---|:---|:---|:---|:---|:---|
| **黑烟密度 0.7-0.95** | 23次 | 能见度~5m，呛咳 | 能见度~2m，**呼吸更困难** | 能见度同健全人但**无听觉导航** | 能见度~0.3m，**只剩中央小孔** | 同健全人但**无法弯腰贴地走** | 视线105cm **完全被烟雾层遮挡** |
| **明火光照** | 86次 | 橙色跳动光源 | 眩光敏感，**辨别力下降** | 只能靠视觉判断火势 | 中心可看但**看不到周边火焰** | 同健全人 | 火焰在**头顶上方**，温度感受更强 |
| **火警铃 85dB** | 31次 | 清晰可闻 | 高频听损，**铃声模糊** | **完全听不到** ⚠️ | 清晰可闻 | 清晰可闻 | 可闻但**不理解含义** |
| **楼梯间烟雾灌入** | 34次 | 呼吸困难，加速下楼 | **每3层必须停**，心率上限触发 | 正常体力但**不知道上面着火** | **视野外全是烟雾**，无法判断安全 | **楼梯完全不可过**，触发绝望循环 | 步幅小，**两级并一级做不到** |
| **电梯禁用标识** | 23次 | 自然走楼梯 | 体力槽加速消耗 | 同健全人 | 无法读标识（低视力）/ 完全不知（全盲） | **致命阻断**—反复按无效按钮 | 够不到按钮/不理解 |
| **爆炸声** | 31次 | 惊吓+方向判断 | 惊吓更强，**方向判断迟钝** | **完全听不到**，靠视觉/振动感知 | 惊吓但可定位 | 同健全人 | 惊吓哭喊，**失去行动能力** |
| **邻里敲门/呼喊** | 11+9次 | 获得信息 | 开门慢，**错过黄金窗口** | **完全听不到敲门** ⚠️ | 可响应但**看不到谁在敲门** | 开门慢 | 够不到门把手/不敢开门 |
| **走廊浓烟** | 45次 | 低头捂鼻快走 | **无法快走**，烟雾暴露时间2-3x | 同健全人 | **视野极小**，容易撞墙/撞人 | 烟雾层在头顶，**坐姿视线更低** | 烟雾层=视线高度，**完全失明** |
| **高温/灼热** | 35次 | 皮肤灼热感+HUD警告 | **耐受力低**，速度衰减更快 | 同健全人 | 同健全人 | 无法脱离热源（**无法奔跑**） | 皮肤更敏感 |
| **通道堵塞** | 4次 | 绕行 | 绕行慢，体力消耗 | 同健全人 | **视野外完全看不到堵塞物** | **窄通道不可过**（需1.5m转弯半径） | 可钻过去但害怕 |

> ⚠️ = 核心教学点（信息断裂/物理阻断），VR独特性最强的体验

### 2.2 听障者"信息断裂"专项映射

听障者的核心困境不是身体障碍，而是**信息可达性鸿沟**（总纲维度4）。下表拆解每个信息事件在听障角色下的具体表现：

| 信息事件 | 健全人接收方式 | 听障者接收方式 | VR实现 |
|:---|:---|:---|:---|
| 火警触发 | 85dB警报（立即） | **闪光灯**（如安装了频闪警报器）/ **完全不知**（如未安装） | 场景中可选择有无频闪设备；无=**完全静默** |
| 邻居敲门警告 | "着火了快跑！" | **完全听不到** / 靠振动感知 | 门不振动，HUD无提示 |
| 消防广播 | 楼内广播循环 | **完全不知** | 无字幕/无手语翻译 |
| 群消息"是不是着火了" | 手机振动+铃声 | 手机**仅振动**（无铃声） | 震动反馈（手柄振动） |
| 爆炸/坍塌方向 | 立体声定位 | **无方向信息** | 仅靠视觉（火光方向）或完全不知 |
| 消防车到达 | 警笛由远及近 | **看不到=不知道** | 无任何提示 |
| 邻居呼救 | "Help!" | **0% 可达** | 完全无声 |

### 2.3 轮椅者"物理阻断"专项映射

| 空间障碍 | 健全人处理 | 轮椅者处理 | VR实现 |
|:---|:---|:---|:---|
| 楼梯 | 正常下楼 | **完全不可通过** | 碰撞体积锁死在楼梯口，显示"❌ 楼梯不可通行" |
| 窄走廊 (<1.2m) | 侧身穿行 | **不可过** | 碰撞体扩大至1.5m直径 |
| 门槛/台阶 (≥5cm) | 一步跨过 | **不可过** | 刚性碰撞，提示"需要协助" |
| 电梯 | 火灾禁用 | **唯一希望破灭** | 按钮可交互但显示"火灾禁用"，可反复按（绝望循环） |
| 避难层入口 | 推开防火门 | 防火门**太重/无自动开门** | 需要等待他人帮助或**放弃** |
| 地面杂物 | 跨过 | **卡轮** | 随机卡轮事件，需玩家摇手柄脱困 |

## 3. 六角色任务树

每个角色的体验设计为 **线性主任务 + 分支决策点**，时长控制在 5-8 分钟（符合VR舒适性）。

### 3.1 阿May（听障，34岁）— MVP首推

```
┌─────────────────────────────────────────────────┐
│ 场景：宏昌阁 2507 · 傍晚 19:00                     │
│ 障碍：听觉信息A（默认）                              │
│ 时长：~5分钟 · 难度：0.60                          │
├─────────────────────────────────────────────────┤
│                                                   │
│  [节点0] 开场                                       │
│  你刚洗完澡摘下助听器，躺在沙发刷手机                   │
│  → 世界完全静默（环境音归零）                          │
│  → 手机群消息震动："25楼是不是着火了？？"              │
│  → 玩家看到文字但听不到任何声音                       │
│                                                   │
│  [节点1] 决策：出去看看？                             │
│  ├─ A. 开门查看 → 走廊已有薄烟（视觉提示）              │
│  │   → 玩家意识到："我在靠眼睛逃命"                   │
│  └─ B. 继续等 → 3分钟后邻居猛烈拍门（震动手柄）         │
│      → 玩家开门，邻居已走，走廊浓烟                    │
│                                                   │
│  [节点2] 下楼梯                                      │
│  楼梯间烟雾渐浓，其他住户匆忙下楼                       │
│  → 玩家正常体力，下楼速度正常                         │
│  → 但**头顶突然一声爆炸**（画面震动+火光，但玩家听不到） │
│  → 其他NPC突然加速奔跑，玩家看到他们惊恐回望            │
│  → 教学点：**信息延迟**—你比别人晚5-10秒知道危险       │
│                                                   │
│  [节点3] 遭遇消防员                                  │
│  消防员对你喊话（无字幕）→ 玩家完全不知他说什么          │
│  → 消防员拉你胳膊，你才意识到要跟你走                   │
│  → 教学点：**紧急情况下听障者的沟通壁垒**              │
│                                                   │
│  [结局] 成功到达避难层                                │
│  复盘：你的信息延迟累计 = 约1分48秒                     │
│  共情提示："阿May听不到警报、敲门、爆炸、消防员喊话。"    │
│  "如果她没看到邻居奔跑，她就还在房间里。"               │
└─────────────────────────────────────────────────┘
```

```

│  → 攥着玩具熊 → 可选择放下（轻装）或抱着（情感锚点）          │
│                                                   │
│  [结局]                                                  │
│  被好心人抱起带到避难层 / 缩在角落等妈妈                      │
│  复盘："在火灾里，King仔看到的是一个腿的森林。"              │
└─────────────────────────────────────────────────┘
```

## 4. 通用游戏机制

### 4.1 核心循环

```
┌──────────────────────────────────────────┐
│                                          │
│  感知环境  →  做出决策  →  执行动作      │
│     ↑                        ↓          │
│     └── 环境实时变化 ←── 产生后果        │
│                                          │
│  每个循环中，障碍模块持续施加限制：        │
│  • 听障：感知环境=缺失听觉通道            │
│  • 视障：感知环境=缺失视觉通道            │
│  • 移动障碍：执行动作=速度/通过性限制     │
│  • 体能障碍：执行动作=耐力限制            │
└──────────────────────────────────────────┘
```

### 4.2 HUD系统

| HUD元素 | 显示内容 | 何时可见 |
|:---|:---|:---|
| **体力槽** | 0-100%，绿色→黄色→红色 | 老年/体能障碍角色始终可见 |
| **时间压力** | 火势当前楼层 vs 玩家所在楼层 | 所有角色 |
| **心率** | BPM，超过阈值触发视线模糊 | 老年/体能障碍 |
| **障碍状态** | 当前激活的障碍模块图标 | 复盘画面 |
| **烟雾密度** | 当前区域烟雾指数 | 环境暗示，非数字显示 |

### 4.3 交互动作库

| 输入 | 动作 | 适用场景 |
|:---|:---|:---|
| 扳机键 | 抓取/开门/拿物品 | 全局 |
| 握持键 | 摸墙（触觉导航） | 视障角色 |
| 摇杆前推 | 移动 | 全局 |
| 摇杆按下 | 蹲下/爬行 | 烟雾层下方 |
| A键 | 呼救（3秒CD） | 全局 |
| B键 | 回头查看 | 轮椅/拐杖（背后视角） |
| 双手柄交替上推 | 推轮椅/爬楼梯 | 轮椅QTE |
| 手柄快速摇动 | 拔拐杖/挣脱 | 拐杖QTE |

## 5. 难度曲线与自适应系统

### 5.1 三档预设

| 预设 | 烟雾 | 火速 | 起始楼层 | 人群拥堵 | 适用于 |
|:---|:---|:---|:---|:---|:---|
| **入门** | 薄烟(能见度8m) | 1层/分 | 12层 | 稀疏 | 首次体验/听障入门 |
| **标准** | 浓烟(能见度4m) | 2层/分 | 22层 | 正常 | 标准体验 |
| **极限** | 黑烟(能见度1.5m) | 3层/分 | 28层 | 拥挤 | 轮椅/全盲等重障碍 |

### 5.2 自适应层

系统可以动态调整（用于研究对照实验）：
- **固定人物 × 可变环境**：测环境恶劣度对共情增量的影响
- **固定环境 × 可变人物**：测不同障碍类型对共情的影响
- **固定一切 × 可变信息提示**：测"是否被告知障碍"对共情的影响

## 6. 共情测量嵌入设计

在游戏中自然嵌入测量点（对标EVRD框架，IJHCS 2025）：

| 测量维度 | 工具 | 游戏中触发点 | 对标文献 |
|:---|:---|:---|:---|
| **情感共情** (emotional) | IRI-Empathic Concern子量表 + self-avatar重叠度(IOS) | 结局后问卷（VR内填写） | EVRD, IJHCS 2025; CHI26 |
| **认知共情** (cognitive) | 锚定任务："估计陈伯下楼需要几分钟？" | 体验陈伯角色前/后各测一次 | CHI26 |
| **行为共情** (behavioral) | 捐助意愿："你愿意为高层火灾无障碍改造捐多少？" | 体验结束后屏 | EVRD, IJHCS 2025 |
| **临场感** (presence) | Slater的SUS临场感量表（6题简版） | 体验后 | Slater, Phil. Trans. R. Soc. B |
| **情境意识** (situation awareness) | SAGAT冻结探针法：随机暂停问"火势在几层？""你现在几层？" | 游戏中2-3次随机冻结 | Endsley SA模型 |
