## 1. 筛选流程总览

```
S0 检索命中 (~8,900)  →  S1 去重唯一URL (8,072)  →  S2 相关性评分 (Keep 52 + Pending 280)
                                                              ↓
S3 正文补抓 (目标 1,000条有正文)  →  S4 五维语义评分  →  S5 人工复核  →  S6 VR编码
                                              │
                                              ├── ≥75: 强推（直接进入S6编码）
                                              ├── 60-74: 人工复核
                                              └── <60: 排除
```

**核心原则**：
- 第一轮粗筛**以标题+URL为主**，快速过滤明显无关条目
- 正文补抓**优先国内/东南亚源**（墙内可访问），兼顾欧美主流通讯社
- 第二轮精筛**必须以正文全文为基础**，评分由大模型自动完成，人工只复核边界案例

## 2. 第一轮：粗筛与正文抓取

### 2.1 检索策略

| 数据源 | 检索式数量 | 时间范围 | 预期命中 |
|:---|:---|:---|:---|
| GDELT DOC 2.0 | 21个 | 2024.06–2026.06 | ~6,000 |
| Google News RSS | 8个 | 同上 | ~1,500 |
| Bing News | 8个 | 同上 | ~1,400 |
| **合计** | **37个** | **24个月** | **~8,900** |

### 2.2 去重与预筛

**URL标准化去重**：
- 去除 `utm_source`, `fbclid` 等追踪参数
- 统一 `http/https` 协议
- 对同一事件的多个镜像源（如 AP 新闻被各地方台转载），保留最早发布或正文最完整的版本

**标题排除词（快速过滤假阳性）**：

| 排除类别 | 关键词 | 示例 |
|:---|:---|:---|
| 山火/野火 | wildfire, forest fire, bushfire, 山火 | "California wildfire spreads" |
| 枪火/冲突 | gunfire, shooting, 枪火, 交火 | "Police exchange gunfire" |
| 比喻/抽象 | fire of passion, under fire (批评), 战火 | "Company under fire for policy" |
| 非住宅建筑 | factory, warehouse, office building (无居住) | "Warehouse fire in Detroit" |

**保留规则**：标题必须同时包含 `fire` 类词 + `building/residential/apartment` 类词，或明确提及 `high-rise/tower`。

### 2.3 六级相关性评分（标题级）

用于快速分类，不替代正文评分：

| 维度 | 命中词 | 加分 |
|:---|:---|:---:|
| 火灾核心 | fire, blaze, inferno, 火灾, 起火 | +2 |
| 建筑类型 | high-rise, apartment, tower, residential, building, 高层, 公寓, 住宅 | +2 |
| 疏散行为 | evacuation, evacuate, escape, trapped, rescue, 疏散, 逃生, 被困, 救援 | +2 |
| 人群描写 | elderly, deaf, blind, child, disabled, resident, 老人, 儿童, 居民 | +3 |
| 文本长度 | 标题字数 > 30字（暗示详细报道） | +1 |
| 排除词 | wildfire, gunfire, under fire, 山火, 枪火 | −5 |

**分级**：
- **High (≥6)**：直接进入 Keep，优先抓正文
- **Medium (3–5)**：进入 Pending，有条件抓正文
- **Low (≤2)**：进入 Eliminate，暂不抓正文

### 2.4 正文抓取策略（分优先级）

**Priority 1 — 高成功率源（国内/东南亚/通讯社）**：
- 中国：新华社、澎湃新闻、财新、新京报、南方都市报
- 东南亚：Channel NewsAsia, Straits Times, Bangkok Post
- 通讯社：AP, Reuters, AFP（镜像站多，成功率高）

**Priority 2 — 中等成功率源**：
- 欧美主流：BBC, CNN, NBC, ABC, CBS, Fox Local
- 地方台：需配合 Playwright 反爬参数

**Priority 3 — 低成功率源（需代理/VPN）**：
- 被墙站点：部分欧美地方新闻、韩国/日本本地媒体

**抓取技术栈**：
```
trafilatura（静态HTML，快） → Playwright headless（JS渲染，稳） → 启发式文本密度提取（兜底）
```

**反爬措施**：
- 随机 User-Agent + viewport
- 注入 JS 隐藏 `navigator.webdriver`
- 模拟人类滚动行为
- 可选代理（`--proxy http://127.0.0.1:7890`）
- 并发控制：2–3线程（避免触发 rate limit）

## 3. 第二轮：五维语义评分

> **前提**：每条待评分新闻必须有 ≥100字 的正文全文。

每个维度 0–3 分，加权总分转换为百分制。满分 = 3×25 + 3×30 + 3×25 + 3×15 + 3×5 = 300分 → 百分制 = 原始总分/3 × 100。

### 维度1：空间可重建性（权重25%）

> **核心问题**：这篇新闻是否提供了足够的三维空间信息，可以直接在VR中重建场景？

| 分数 | 标准 | 示例特征 |
|:---|:---|:---|
| **0** | 无任何空间信息 | 仅提及"某地发生火灾" |
| **1** | 仅提楼层/建筑类型 | "XX公寓12楼起火"，无更多空间细节 |
| **2** | 有楼栋结构/楼梯/烟雾位置等部分空间信息 | "火从4楼楼梯间蔓延到走廊"，"浓烟从门缝涌入" |
| **3** | 完整空间动线可重建，含楼层、房间、走廊、楼梯、烟雾扩散路径 | "起火点位于14楼卧室，浓烟沿楼梯间向上扩散至18楼，走廊可见度不足1米，居民从消防通道向下疏散" |

**来源依据**：总纲 §4.2 叙事轴A"空间动线"；📖 EVRD (IJHCS 2025) 发现空间临场感驱动情感共情；📖 CHI 2026 证明空间临场感提升情感换位。

### 维度2：弱势群体叙事深度（权重30%）

> **核心问题**：新闻是否深入描写了弱势群体在火灾中的具体处境和身体体验？是否避免刻板印象？

| 分数 | 标准 | 示例特征 |
|:---|:---|:---|
| **0** | 未提及任何弱势群体 | 纯火灾事实报道 |
| **1** | 仅提及统计数字或标签 | "遇难者中有3名老人"，无进一步描写 |
| **2** | 有群体特征/行为描述 | "老人因行动缓慢落在人群后面"，"儿童被浓烟吓得不敢动" |
| **3** | 有个体第一人称叙事，描写身体×环境的耦合体验 | "65岁的江先生扶着墙一步步往下挪，每走三层就停下来大口喘气。火警铃在响，但他高频听损，只听到模糊的嗡嗡声。" |

**特别排除**：如果新闻以"残疾人很可怜/无助"为叙事框架（怜悯视角），应降级1分。优先选呈现**环境失败**（如"警报只有声音没有闪光灯，听障者完全不知道"）而非个人缺陷的叙事。

**来源依据**：总纲 §4.2 叙事轴B"身体×环境耦合"；📖 CHI 2021 (Tigwell) 指出"失能模拟"应避免怜悯视角、需呈现真实生活经验；📖 Virtual Reality 2025 验证第一视角视障模拟提升共情；📖 CHI 2026 指出认知共情来自理解"环境对身体的限制"而非情感煽情。

### 维度3：叙事完整度（权重25%）

> **核心问题**：新闻是否构成了一个完整的叙事？是否有起承转合、决策点和情感转折？

| 分数 | 标准 | 示例特征 |
|:---|:---|:---|
| **0** | 简讯/快讯，无叙事 | "某地高层起火，X人受伤，原因调查中" |
| **1** | 基本事实报道，有简单过程 | 有起火时间/地点/伤亡/救援，但无叙事展开 |
| **2** | 有过程描写+情感/引语 | 包含目击者引语、疏散过程描述、情感反应 |
| **3** | 完整叙事弧：情境→冲突→决策→结局，多视角 | 从起火前到救援结束的完整叙事，有决策点描写、情感转折、多人视角 |

**来源依据**：📖 Cultivating empathy through narratives in VR (Pers. Ubiquitous Comput., 2024) 综述指出叙事驱动共情的关键是完整的故事弧；📖 LegacySphere (CHI 2024) 的具身叙事设计方法；总纲 §4.2 叙事轴C"决策与情感"。

### 维度4：VR转化潜力（权重15%）

> **核心问题**：这篇新闻的叙事元素能否直接映射到VR交互机制？

| 分数 | 标准 | 示例特征 |
|:---|:---|:---|
| **0** | 不可转化 | 纯统计报告/政策讨论，无场景元素 |
| **1** | 部分元素可用 | 有建筑类型/火灾原因等背景信息，但缺乏具体交互点 |
| **2** | 可做单场景VR | 有明确的空间+角色+冲突，可直接做单一关卡 |
| **3** | 可转完整VR关卡，含多决策分支 | 有完整空间动线+角色困境+多个决策点+时间压力，可直接映射到[总纲 §5 游戏机制](../总纲_VR高层火灾共情系统.md#5-游戏机制) |

**来源依据**：📖 Immersive Storytelling for Co-creation in XR (ICIDS) 的四维框架；📖 Spatial Narrative–Driven Emotion-Oriented Design for VR Serious Games (2025)；总纲 §4.3 四个VR转译维度。

### 维度5：来源权威性（权重5%）

> **核心问题**：信息来源的可靠程度？

| 分数 | 标准 | 来源示例 |
|:---|:---|:---|
| **0** | 不可靠来源 | 匿名博客、社交媒体帖子 |
| **1** | 地方小报/聚合站 | 地方新闻网站、新闻聚合器 |
| **2** | 主流通讯社/知名媒体 | AP, Reuters, BBC, 新华社, 财新, 澎湃 |
| **3** | 官方调查报告/学术文献 | Grenfell Tower Inquiry, NIST报告, NFPA, 同行评审论文 |

**来源依据**：PRISMA 系统综述指南中的来源质量评估标准。

## 5. 操作指南

### 5.1 正文补抓命令

```bash
# 先跑 Keep（高优先级）
python 工作流/refetch_fulltext_playwright.py --input 工作流/第三轮_含正文.csv --only-keep --workers 3

# 再跑 Pending（中等优先级，可分批）
python 工作流/refetch_fulltext_playwright.py --input 工作流/第三轮_含正文.csv --only-pending --workers 3

# 如需代理（VPN）
python 工作流/refetch_fulltext_playwright.py --input 工作流/第三轮_含正文.csv --only-keep --proxy http://127.0.0.1:7890 --workers 2
```

### 5.2 五维评分命令

```bash
# 对 Keep 评分
python 工作流/score_articles.py --input 工作流/第三轮_含正文.csv --only-keep --output 工作流/第三轮_含正文_精筛.csv

# 对 Pending 评分（正文补完后）
python 工作流/score_articles.py --input 工作流/第三轮_含正文.csv --only-pending --output 工作流/第三轮_含正文_精筛_pending.csv
```
