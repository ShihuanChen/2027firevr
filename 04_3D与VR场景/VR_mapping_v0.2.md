# VR mapping v0.2

VR 场景以多条新闻中重复出现的机制为依据，再进行可控的设计综合。

| 编码机制 | VR 表达 |
|---|---|
| 线索出现/气味早期线索 | 低明确度提示、空间音频、视觉烟雾、可选嗅觉扩展 |
| 线索到确认 | 玩家主动开门、观察猫眼、接收邻居消息、确认烟火 |
| 解释间隙 | 允许先把异味或骚动理解为日常情况，再由新证据纠正 |
| 行动断点 | 在感知、决定、通行、操作或求助处触发不同反馈 |
| 动态可行动空间 | 烟雾、火势、门、电梯和救援状态随时间改变路径 |
| 社会信息中介 | NPC 敲门、电话、群组消息、消防员指引，带来源和时序 |
| 社会行动支架 | 抬轮椅、协助开门、逐户通知、共同搬运或等待救援 |

固定剧情骨架保证实验可比，局部探索和状态规则保留新闻中反复出现的变化。单条新闻提供证据，多条新闻共同决定机制；VR 不复刻某一篇报道的全部细节。
