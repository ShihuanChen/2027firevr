# 文生 3D 开源模型调研（用于"新闻语料 → VR 场景"可行性评估）

> 调研日期：2026-08-20。目标：找效果稳定、可调用 API 的开源 text-to-3D 模型，验证能否用筛选出的火灾新闻素材生成 3D 场景。

## 一、核心结论（先看这个）

1. **腾讯 Hunyuan3D（混元3D）是最契合本项目的首选**：开源 + 有官方 API（腾讯云国际站）+ 中文文档 + 支持 PBR/自动绑定，且腾讯另有 **HunyuanWorld** 大世界模型可做"场景/环境"级生成（单体物体之外）。
2. **Microsoft TRELLIS / TRELLIS.2（MIT 许可）是质量最高的开源 image-to-3D 方案**，可本地跑（需 24GB 显存跑 4B 模型），适合对质量与可控性要求高的物体。
3. **关键限制**：当前所有 text-to-3D 工具都是**为"单个孤立物体"优化**的，不支持直接生成"整层着火楼梯间"这类复合场景。因此新闻素材→3D 的正确工作流是：**把场景拆成物体（楼梯/轮椅/火警铃/浓烟体/窗）→ 逐个生成 → 在 Unity/Unreal/Blender 里合成**。或直接 **text→image→3D 两阶段**（先出概念图再转 3D，质量显著优于直接文生 3D）。

## 三、与本项目的映射（新闻素材 → 3D 资产）

筛选出的 109 条正式 + 16 篇补充素材，按 SAVTBC 六维拆成可生成对象：

- **S 空间**（高层/楼梯间/窗/阳台）→ 建筑构件：楼梯段、防火门、窗户、阳台栏杆
- **B 身体 × 环境**（轮椅被楼梯阻断、浓烟、高温）→ 关键叙事物体：轮椅、坡道、浓烟体积、烧焦门框
- **A 声音**（火警铃、邻里呼喊）→ 可交互物件：85dB 火警铃（听障角色"看不见"）、敲门互动点
- **C 社交**（邻里互助、家庭单元）→ 人物组合：母救子、邻里拍门

**建议生成单元（pilot 先用 3–5 条新闻试）**：
1. 罗姐（轮椅）"距楼梯 3 米却跨不过" → 生成「楼梯 + 轮椅 + 5cm 门槛」三件套
2. 宏福苑"无声警报" → 生成「85dB 火警铃 + 邻里拍门角色」
3. 阿May「黑烟灌入楼梯间」→ 生成「楼梯间 + 浓烟体积 + 低能见度」环境块

## 四、推荐工作流（两阶段，质量优先）

```
新闻文本（SAVTBC 标签）
   ↓ 拆解为物体清单 + 质感/尺度提示词
text → image（Midjourney / SD / 即梦，出概念图）
   ↓
image → 3D（Hunyuan3D 或 TRELLIS.2，图生3D 优于文生3D）
   ↓ 输出 GLB/OBJ
在 Unity/Unreal/Blender 合成场景 + 接身体×环境耦合参数
```

## 五、测试前置条件（待用户确认）

- **Hunyuan3D API 测试**需腾讯云国际站 API Key（注册送 200 免费额度）。当前环境无 Key，无法立即跑通；拿到 Key 后可用 Python SDK 对 3–5 条新闻做 pilot。
- **本地 TRELLIS.2** 需 24GB 显存 GPU（A100/H100 或租 Vast.ai ~0.5 美元/小时）；本机当前无此算力。
- 下一步建议：先申请 Hunyuan3D API Key，用上述 3 条 pilot 新闻跑通 text→image→3D，评估生成物与 VR 关卡参数的可用度，再决定是否纳入方法章节作为"场景生成"模块。
