# Design Space

## 一、背景

核心问题：标注为了什么？每个标签要对应论文要填的 gap。以下把每个维度直接挂到 gap 上，确保编码出来能直接支撑论点。本文档为 **v2 精简版**

|编号|Research Gap|对应 v2 标注维度|label|
|---|---|---|---|
|G0|现有火灾新闻以 2D 文本/视频呈现，读者是旁观者，难以具身理解"人如何被困、为何困住"，弱势群体处境被系统性忽视|全部维度（整体动机）|把新闻转成可重建的 VR 设计参数，使 VR 补足 2D 缺失的具身共情|
|**G1**|沉浸式新闻多为旁观者/上帝视角，缺乏第一人称、身体化的叙事；叙事聚焦个体悲情多于系统性反思|第一遍·新闻故事标注：① 视角、② 叙事视角、③ 叙事结构|标注每篇的叙事人称与立场，论证"现有新闻缺什么视角、VR 该补什么视角"|
|**G2**|2D 新闻无法提供空间音频、触觉/温度、身体限制模拟、感知剥夺等具身反馈，这些是 VR 促共情的核心机制，却未被系统梳理|第二遍·VR 设计标注：机制一·氛围叙事、机制二·交互|标注每条可用的共情机制与多模态反馈，直接映射"2D 没有、VR 独有"的设计空间|
|**G3**|弱势群体（老年/残障/儿童/孕妇/独居）在火灾中的具体处境困难被忽视|E1 身体主体 \+ 两大机制中的 V 拆解项（V\_framing、V处境困难）|标注处境主体与"框架/困难"类型，使 VR 把系统性忽视转成可体验的处境|
|**G4**|缺乏把新闻语义转成 VR 空间/感官参数的中间层|底层支撑：S1 空间层级、S2 感官主导（写入 ④ VR 可模拟性 \& 氛围叙事机制）|作为 ④ 与两大机制的描述底料，不单列编码维度|

## 二、两遍标注法总览

每条新闻做两遍标注：第一遍从"新闻文本"侧提取叙事特征（5 维），第二遍从"VR 设计"侧提取可重建参数（E1 人物 \+ 2 大机制）。两遍共同支撑"新闻 → VR 场景"的桥接。

|维度|字段名|类型|取值 / 说明|
|---|---|---|---|
|①|视角|单选|第一人称 / 第三人称 / 混合|
|②|叙事视角|单选|幸存者第一人称 / 目击者·邻居 / 救援者 / 家属·亲友 / 官方·媒体全知 / 混合多视角|
|③|叙事结构|单选|线性 / 倒叙 / 多线|
|④|VR 可模拟性|文本|只标可用 VR 制造冲突感/临场感的正文片段|
|⑤|情感标签|单选|恐惧 / 悲伤 / 愤怒 / 无助 / 希望 / 其他|
|E1|身体主体|多选|普通成年人 / 老年人 / 儿童 / 轮椅使用者 / 视障者 / 听障者 / 拄拐·助行器 / 孕妇·抱婴者 / 宠物 / 救援者|
|M1|氛围叙事机制|多选|信息呈现 / 多模态感知剥夺 / 环境模拟 / V\_framing|
|M2|交互机制|多选|E3 交互 / E5 / E6 / 限制模拟 / V处境困难|

## 三、第一遍：新闻故事标注（5 维）

### ① 视角（语法人称）

定义：文本以何种语法人称叙述。证据：正文主语是"我/我们"（第一人称）还是"他/居民/消防"（第三人称），或交替出现（混合）。

|取值|判定证据|
|---|---|
|第一人称|当事人自述、"我逃到楼梯口""我们被烟困住"|
|第三人称|记者/媒体转述、"一名老人被困""消防赶到"|
|混合|引语插入当事人原话 \+ 媒体叙述交织|

### ② 叙事视角（内容立场，原 E4 并入）

定义：叙述的声音来自谁，区分"语法人称"与"内容立场"。证据：信息来源是亲历者、旁观者、救援方、家属还是官方/媒体全知。

|取值|判定证据|
|---|---|
|幸存者第一人称|当事人直接讲述自身经历|
|目击者·邻居|同楼/周边居民、邻居转述|
|救援者|消防/医护/志愿者视角|
|家属·亲友|遇难/受灾者亲属视角|
|官方·媒体全知|记者调查、政府通报、数据汇总|
|混合多视角|多来源拼合|

### ③ 叙事结构（仅时间维度）

定义：事件在时间上的排布方式，决定 VR 关卡顺序与闪回机制。原方案的"因果结构/冲突结构"并入 ④ VR 可模拟性与核心冲突描述，不单列。判定：≥3 个独立空间/时间线并行为"多线"；以回忆/回溯展开为"倒叙"；否则"线性"。

|取值|判定证据|
|---|---|
|线性|起火→蔓延→逃生/救援单线推进|
|倒叙|从灾后/纪念切入再回溯事故|
|多线|≥3 个空间或家庭线并行（如多户、多楼层同时发生）|

#### 取值区分详解

|取值|核心判断|典型特征与例子|
|---|---|---|
|**线性**|按时间先后从头到尾讲，一条直线|• 结构：起火→蔓延→逃生/救援→结果<br>• 时间词多："首先""然后""接着""最终"<br>• 例：阿卡德尔菲亚公寓火灾（6:24接警→6:29到达→8点控制→居民采访）|
|**倒叙**|先给结果/现在的状态，再回头讲经过|• 开头出现："已经""事后""上周""几个月后""在法庭上"<br>• 结构：现在的结果→回溯火灾经过<br>• 例：格伦费尔塔纪念碑辩论（从议会演讲切入→回溯2017年火灾）；普尔曼男子纵火认罪（从法院认罪→回溯10月火灾）|
|**多线**|同时讲多个人/多个地点/多个事件，多条线并行或交叉|• 频繁切换人名/地点/楼层<br>• 出现："与此同时""另一方面""另一起""在另一栋楼""某某（某楼层）的经历是"<br>• 例：德里\+印多尔\+艾哈迈达巴德\+昌迪加尔四地火灾综合报道；格伦费尔塔8个幸存者的不同逃生经历；纽约布鲁克林\+布朗克斯两起致命火灾|

#### 快速判断流程

1. 读完第一段→这是在讲"结果/现在"吗？→ 是→后面开始回溯经过→**倒叙**

2. 否→文章在讲多个人/多个地方吗？→ 是→**多线**

3. 否→按时间顺序从头到尾→**线性**

**易混点**：倒叙≠有回忆。倒叙是整篇文章的结构从结果切入；线性叙事中人物回忆过去不算倒叙。多线≥3条独立线，只有2条线（如"居民\+消防员"）仍算线性。

### ④ VR 可模拟性（新闻 → VR 的桥）

定义：只摘出"可用 VR 制造冲突感/临场感"的正文片段，写成自由文本摘要。证据：哪些空间障碍、身体限制、感官刺激、交互动作可被程序化还原。这是新闻侧到 VR 侧的关键桥接字段。

写法示例："疏散通道被杂物堆积、消火栓被遮挡、防火门闭门器损坏→环境障碍 \+ 交互限制"；"烟花射入阳台起火、住户天台撤离跳至相邻楼→空间路径 \+ 移动方式"。

### ③\-1 叙事颗粒度（动作 / 场景 / 情绪 / 数据）

定义：一条新闻被拆解、还原到「多细的程度」来做 VR 场景重建。从具体到抽象分四档，可多选（一条新闻可同时支撑多档）。判定依据——看这条新闻能支撑到哪一层：

|取值|判定依据（正文里出现什么就选）|
|---|---|
|数据级|只有伤亡数字、时间、政策、统计、纯文字论述，无具体空间或动作|
|场景级|有具体空间（楼层、通道、房间、楼梯、阳台、街道），可还原环境布局|
|动作级|有"他怎么做、往哪跑、怎么躲、推门/爬窗/背人"等具体身体动作|
|情绪级|突出心理/氛围/孤立无援感，能驱动共情而非仅还原事实|

示例："火灾造成 79 人死亡，凌晨 2 点起火" → 数据级；"14 楼阳台被火光映红、楼道堆满杂物" → 场景级；"他背着老人从楼梯走下来" → 动作级；"浓烟中找不到楼梯，只剩哭声" → 情绪级。一条新闻可同时勾 场景级\+动作级\+情绪级。

### ⑤ 情感标签（原 N5 情感弧线 \+ N7 语气合并）

定义：整篇主导情感，固定六类。证据：正文高频情绪词与叙事基调。纪念/创伤类可标"其他"并在备注说明。

|取值|判定证据|
|---|---|
|恐惧|火势逼近、呛烟、无处可逃的惊惧|
|悲伤|遇难、失联、家园尽毁的哀痛|
|愤怒|对管理失职、责任缺失的愤慨|
|无助|设施失效、求援无门的无力|
|希望|成功疏散、互助救援、整改见效|
|其他|纪念/创伤/复杂混合，备注具体|

## 四、第二遍：VR 设计标注（E1 人物 \+ 2 大机制）

### E1 身体主体（人物）

定义：场景中被具身化的主体是谁。证据：正文点名的受灾/相关人群。可多选。

|取值|判定证据|
|---|---|
|普通成年人|一般住户、上班族|
|老年人|独居/行动迟缓长者|
|儿童|婴幼儿、学龄儿童|
|轮椅使用者|无法走楼梯者|
|视障者|依赖触觉/听觉导航|
|听障者|接收不到警报|
|拄拐·助行器|移动受限长者|
|孕妇·抱婴者|双重负担|
|宠物|需带离的动物|
|救援者|消防/志愿角色|

### 机制一·氛围叙事（原 ①②③⑤⑦ \+ E2 信息呈现/多模态感知剥夺/环境模拟 \+ V framing）

定义：VR 用何种"氛围与叙事手法"让使用者临场。可多选。V 层（少数群体共情）太抽象不好单条标，其"框架\(framing\)"拆入此处。

|取值|判定证据|
|---|---|
|信息呈现|用标识/广播/字幕披露隐患与风险（如消火栓被遮、通道堵塞）|
|多模态感知剥夺|模拟烟中视线丧失、警报听不清、气味呛人|
|环境模拟|火光、高温、烟雾、结构坍塌的物理环境|
|V\_framing|把"系统性忽视的弱势群体处境"作为叙事框架呈现<br>### 机制一·子维度判定细则（氛围叙事机制字段）<br>以下为 Base「氛围叙事机制」字段各取值的选项含义与判定依据，判定依据只看新闻正文里有没有对应的氛围/叙事手法信号。<br>信息呈现：用文字/图标/UI/数据可视化直接展示信息。判定：报道里有伤亡数字、时间线、楼层信息、地图、官方通报。<br>多模态感知剥夺：同时削弱多种感官，制造脆弱与不确定性。判定：浓烟\+黑暗、听不清看不清、感官过载或缺失。<br>环境模拟：直接重建火灾发生的物理环境。判定：报道描述具体空间（楼层、房间、通道、楼梯、阳台、街道）。<br>V\_framing：用构图/镜头语言/视角选择引导情绪，突出系统性忽视的弱势群体处境。判定：报道强调"从窗户看到的景象"、俯视/仰视、特写某个瞬间、少数群体框架。<br>联动：多模态感知剥夺常配共情机制·感知剥夺 \+ 沉浸反馈·视觉遮挡/空间音频；环境模拟常配社会见证/后果呈现；V\_framing 常配亲密关联/后果呈现；信息呈现常配数据级叙事颗粒度。|

### 机制二·交互（原 E3 \+ E5 \+ E6 \+ E2 限制模拟 \+ V 处境困难）

定义：使用者在 VR 中"能做什么/被限制什么"，制造能动性张力。可多选。V 层的"处境困难"拆入此处。

|取值|判定证据|
|---|---|
|E3 交互|开门/破门、破窗/跳窗、引导路径、呼救等可交互动作|
|E5|移动方式：走/爬/扶梯/跳相邻楼等|
|E6|交互动词：开门、破窗、背负、指引等|
|限制模拟|门打不开、电动装置故障、逃生门上锁等约束|
|V处境困难|弱势群体特有的移动/感知/信息获取困难<br>### 机制二·子维度判定细则（交互机制各字段）<br>以下为 Base 中「交互机制」下各子字段的选项含义与判定依据。所有判定只看新闻正文里是否出现对应信号，不凭推测。<br>交互\_移动方式（用户怎么移动）：自由行走=摇杆自由移动无预设路线；瞬移/节点跳转=点选位置跳过去、跨楼层大空间；受限移动（轮椅/拄拐/爬行）=移动能力被刻意限制、报道提老人/残障/伤员/被困楼层；固定点位=站在固定位置只能转头看、旁观；引导路径=系统给推荐路线、展示完整逃生过程。联动：先定身体主体和叙事颗粒度，移动方式基本就出来——弱势群体/被困→受限移动；旁观→固定点位；展示撤离→引导路径；开放探索→自由行走；跨楼层→瞬移。<br>交互\_视角转换（视角会不会变、怎么变；联动叙事结构）：角色切换=不同身份各经历什么（多线/多人物）；身体替换="如果我身体不同"、强调具身共情；时间回放="火灾前 vs 后""如果当时"（倒叙/闪回）；上帝视角/俯瞰=有建筑/楼层图、街区图、救援部署；同步多视角=同一时刻多个当事人的声音/动作（分屏/画中画）；无转换=单人物线性单线、从头到尾一个视角。<br>交互\_共情机制（用什么手段激发共情，可多选，从情感标签倒推）：感知剥夺=削弱视觉/听觉/触觉制造不确定与恐惧（浓烟遮蔽、黑暗中只听见声音）；身体限制模拟=让用户体验行动受限的身体（老人爬不动、轮椅下不了楼、门打不开）；时间压力=倒计时/火势逼近制造紧迫感（"还剩几分钟""火已烧到门口"）；社会见证=看到他人痛苦反应与互助行为（邻居呼救、消防员救援、家属哭泣）；后果呈现=展示灾后伤亡/废墟/生活破碎（事后照片、遇难者名单、家庭叙述）；道德选择=让用户面临两难抉择（救谁、是否冒险返回、先救谁）；亲密关联=通过具体人物关系建立情感连接（母子分离、宠物被困、情侣最后通话）。联动：恐惧→感知剥夺\+时间压力；无助→身体限制模拟\+感知剥夺；悲伤/愤怒/希望→社会见证\+亲密关联\+后果呈现；有具体人物关系→亲密关联；有抉择情节→道德选择。<br>交互\_沉浸反馈（用什么感官通道给即时反馈，可多选，从共情机制派生；判定依据=正文出现什么就选）：空间音频="哭声从楼上传来""火声从左侧逼近""脚步声在身后"；视觉遮挡="浓烟中看不见""视线被遮挡""灯光闪烁""眼前一片黑"；温度/震动="门把手烫得握不住""热浪扑面""地板震动""爆炸震动"；手柄/触觉阻力="推门推不开""拉人拉不动""爬窗被卡住""身体被挤住"；心跳/呼吸UI="心跳越来越快""喘不过气""倒计时"；字幕/手语/振动提示=有对话/证词/关键信息需接收，或涉及听障/无障碍。联动：感知剥夺→视觉遮挡\+空间音频；身体限制→手柄阻力\+温度/震动；时间压力→心跳/呼吸UI；任何叙事→字幕/手语/振动提示（无障碍兜底）。<br>交互\_场景控制（故事推进方式由谁控制）：线性叙事=只想让人"亲身经历一遍"、清晰时间线；分支选择=想让人思考"换种选择会怎样"、有"如果当时"抉择点；沙盒探索=想让人自由查看现场各处、空间细节丰富无单一主线；重复训练/纠错=想让人学会怎么逃生/救人、报道作演练案例；博物馆/纪念碑陈列=重在纪念/反思/保存记忆、纪念墙/遇难者名单/遗址。联动：线性/倒叙叙事→线性叙事控制；多线叙事→分支选择或沙盒探索；后果呈现/纪念→博物馆/纪念碑陈列。|

#### 困境类型标签说明（补充子分类）

以下标签用于更精细地标注新闻中人物面临的困境类型，可作为"限制模拟"与"V处境困难"的子分类参考。单选时需确定**核心困境**。

|标签|回答的问题|判定证据与例子|
|---|---|---|
|**逃生vs被困**|这个人**最终出来了没有**？（结果状态）|• 逃生：离开了危险区域（自己跑/被拉/跳出来）<br>• 被困：还在危险区域里，出不来（等救援/遇难）<br>• 例："消防员破门救出被困卧室的一家四口"→被困；"居民用湿毛巾捂鼻爬下20楼"→逃生|
|**自救vs互救**|是**自己救自己**还是**别人帮的**？（救援方式）|• 自救：当事人主动采取行动（用湿毛巾、爬消防梯、跳楼、打电话报警）<br>• 互救：当事人之间互相帮助（邻居敲门提醒、接孩子、架人下楼梯、共享湿毛巾）<br>• 例："邻居爬上消防梯进入浴室救出三个孩子"→互救；"少女用母亲纱丽扔给二楼被困男子系在阳台爬下来"→自救\+互救|
|**信息缺失/警报延迟**|当事人**知不知道起火了**？（信息传递）|• 警报没响、警报延迟、居民不知道起火、靠邻居敲门/手机消息才知道<br>• 例：宏福苑火灾多位居民"没听到警铃，靠社区群组消息才知道"；柏林囤积者公寓"其他楼层烟雾报警器响了，但被困者没听到"|
|**时间压力**|有没有**来不及**的感觉？（时间紧迫性）|• 火势蔓延太快、逃生时间不够、黄金救援期、与时间赛跑、"几分钟内整栋楼被烟笼罩"<br>• 例：上海静安大火"烟囱效应3分钟吞整栋楼"；南京明尚西苑"电动车架空层起火，黄金救援期仅3分钟"|
|**建筑/设施缺陷**|楼本身**有没有问题**？（硬件条件）|• 消防通道堵塞、喷淋失灵、防火门损坏、消防栓没水、云梯够不着、自动关闭门缺陷、烟雾探测器失灵、疏散通道被杂物占用<br>• 例：因伍德公寓"117起未整改违规，包括缺陷自动关闭门和失灵烟雾探测器"；广州高层调查"消火栓被杂物埋没、14个防火门闭门器损坏"|
|**身体限制vs环境障碍**|逃不出来/逃生难，**怪身体还是怪环境**？（困难原因）|• 身体限制：人自身条件（高龄、残疾、坐轮椅、孕妇、婴幼儿、受伤、肥胖、行动不便）<br>• 环境障碍：外部条件（浓烟封路、楼梯着火、门打不开、电梯停运、消防梯够不着、通道被堵）<br>• 例："80岁坐轮椅老人困在三楼"→身体限制；"年轻人因楼梯被火焰封锁困在阳台"→环境障碍|

#### 重点区分：逃生vs被困 vs 身体限制vs环境障碍

**逃生/被困** = 结局怎么样（出来了没）——看**结果**
**身体/环境** = 为什么会这样（怪自己还是怪外面）——看**原因**
两者是**互补关系**，不是二选一：一条新闻可同时标"被困\+身体限制"（坐轮椅老人困在楼里），也可标"逃生\+环境障碍"（年轻人冲破浓烟逃出）。

#### 单选时如何确定核心障碍（多人物新闻）

当一篇新闻中有不同的人面临不同的主要障碍时，按以下优先级判断：

1. **导语/标题原则**（最优先）：新闻开头前两段重点写了谁的困境，那个人的障碍就是核心。标题写"80岁老人被困三楼"→身体限制；标题写"楼梯被火封，居民阳台呼救"→环境障碍。

2. **主角原则**：整篇文章围绕谁展开，谁的经历占篇幅最多，就以谁为准。

3. **最严重/最极端原则**：篇幅差不多时，选后果最严重、最戏剧化的那个。有人被困但获救，有人被困遇难→以遇难者的障碍为准。

4. **结构性原因原则**：以上都分不清时，问"这场灾难之所以严重，根本上是因为什么？"——楼的问题→环境障碍；人的问题→身体限制。

**兜底原则**：火灾新闻中"环境障碍"通常是默认项——火灾本身就是环境威胁，大多数人逃不出来首先是因为烟、火、通道被封。只有当文章**明确强调**某个人的身体条件是主要困境时，才标"身体限制"。
