## 复现路径

```bash
# 1. 编码集与输入包（已定版，直接用）
repo/05_编码包/编码集v4_事件.csv        # 94 行，事件层元数据
repo/05_编码包/输入包_编码集v4.csv      # 96 行，喂模型只取 切片ID/标题/正文

# 2. 打标（三家模型各跑一次，逐条、temperature=0）
repo/05_编码包/提示词与交付_v4_单条.md  # 整块复制提示词
# 结果存为 结果_模型A.jsonl / 结果_模型B.jsonl / 结果_模型C.jsonl

# 3. 合并与一致性
cd repo/05_编码包 && python 合并与一致性.py
# 出四表：合并结果.csv / 一致性.csv / 待人工抽检.csv / off_axis汇总.csv

# 4. 验证（34 档覆盖、逐档 κ 与 PABAK）
cd repo/06_工作流产物/第17轮_终补搜与验证_20261022
python merge_labels.py            # 96 条参考标注 → 覆盖统计.json
python codebook_validation.py     # 逐字段 κ、bootstrap CI、逐档 PABAK

# 5. 补搜（第三轮，F6 专项）
python search3.py                 # 32 查询 × 10 语种 → 补搜3_候选.csv
```

一致性判读门槛：κ ≥ 0.6 该轴可写进论文；κ < 0.4 判定线必须改；off_axis > 15% 该轴不穷尽。
**逐档一致性必须同时报 PABAK**（2Po−1），只报 κ 会在极端边际下假性归零。

## 关键结论（可直接引用）

1. 60 个事件组只对应 25 起真实火灾，宏福苑与 Bronx 两簇占 122 篇的 69%，按篇统计会失真。
2. 通稿判据：过程类细节 ≤ 2 且非过程类 ≥ 4。
3. 宽查询补搜合格率 0.2%，新增细节类型 0，缺的不是检索词而是报道体裁。
4. 旧输入包与编码集错配，导致"D4 = 0"是假空缺；补齐后 D4 有 5 例。
5. **A2（单通道）+ A5（无信号）合计 55/96 = 57%**，语料里的火灾绝大多数是"只拿到一条线索"或"什么也没拿到"。VR 的主场景是信息稀缺下的判断。
6. **C6（无路可走）30 例、D5（跳楼悬窗）19 例**，路径归零不是极端个案，是常规结局。
7. **F6 听障是媒介空缺而非语料空缺**：57 条候选中死亡通报 12、消防科普 15、邻居证人 8、调查司法 10，有当事人过程的仅 2 条，且两例都以死亡告终、都明确写到缺少视觉警报。
8. 逐档 κ 出现五个 0.000（C1、C6、E4、E5、F8），PABAK 分别为 0.767 / 0.900 / 0.967 / 0.967 / 0.933，属 prevalence problem，不是分歧。
9. 91% 的事件只有 1 篇可重建报道，故取事件数优先：94 起 / 96 篇。
