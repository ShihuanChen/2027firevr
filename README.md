## 复现路径

```bash
# 1. 编码集与输入包（已定版，直接用）
repo/05_编码包/编码集v4_事件.csv        # 94 行，事件层元数据
repo/05_编码包/输入包_编码集v4.csv      # 96 行，喂模型只取 切片ID/标题/正文

# 2. 打标（三家模型各跑一次，逐条、temperature=0）
repo/05_编码包/提示词与交付_v4_单条.md  # 整块复制提示词
# 结果存为 结果_模型A.jsonl / 结果_模型B.jsonl / 结果_模型C.jsonl

# 3. 合并与一致性
cd repo/05_编码包 && python 合并与一致性.py
# 出四表：合并结果.csv / 一致性.csv / 待人工抽检.csv / off_axis汇总.csv
```

一致性判读门槛：κ ≥ 0.6 该轴可写进论文；κ < 0.4 判定线必须改；off_axis > 15% 该轴不穷尽。

## 关键结论（可直接引用）

1. 60 个事件组只对应 25 起真实火灾，宏福苑与 Bronx 两簇占 122 篇的 69%，按篇统计会失真。
2. 通稿判据：过程类细节 ≤ 2 且非过程类 ≥ 4。
3. 宽查询补搜合格率 0.2%，新增细节类型 0，缺的不是检索词而是报道体裁。
4. 旧输入包与编码集错配，导致"D4 = 0"是假空缺；补齐后 D4 有 4 例。
5. F5/F6 为零属报道体裁空缺，F6 无法靠补搜解决，写入 limitation。
6. 91% 的事件只有 1 篇可重建报道，故取事件数优先：94 起 / 96 篇。
