## 关键结论（可直接引用）

1. 60 个事件组只对应 25 起真实火灾，宏福苑与 Bronx 两簇占 122 篇的 69%，按篇统计会失真。
2. 通稿判据：过程类细节 ≤ 2 且非过程类 ≥ 4。
3. 宽查询补搜合格率 0.2%，新增细节类型 0，缺的不是检索词而是报道体裁。
4. 旧输入包与编码集错配，导致"D4 = 0"是假空缺；补齐后 D4 有 5 例。
5. **A2（单通道）+ A5（无信号）合计 62/106 = 58.5%**，语料里的火灾绝大多数是"只拿到一条线索"或"什么也没拿到"。VR 的主场景是信息稀缺下的判断。
6. **C6（无路可走）32 例、D5（跳楼悬窗）19 例**，路径归零不是极端个案，是常规结局。
7. **F6 听障是媒介空缺而非语料空缺**：57 条候选中死亡通报 12、消防科普 15、邻居证人 8、调查司法 10，有当事人过程的仅 2 条，且两例都以死亡告终、都明确写到缺少视觉警报。
8. 逐档 κ 出现五个 0.000（C1、C6、E4、E5、F8），PABAK 分别为 0.767 / 0.900 / 0.967 / 0.967 / 0.933，属 prevalence problem，不是分歧。
9. 97% 的事件只有 1 篇可重建报道，故取事件数优先：103 起 / 106 篇。
10. **缺口是可补的**：第四轮 23 条查询把 F4 从 1 例补到 11 例，E4、E5 各补 1 例。此前判为"报道盲区"的两档，真实原因是查询没打到"协助疏散"与"官方建议返家"这类表述。
