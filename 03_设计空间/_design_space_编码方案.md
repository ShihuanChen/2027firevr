# VR 高层火灾共情系统 · 新闻语料 Design Space 与人工编码方案

> **用途**：对保留语料进行人工 coding，把新闻报道转化为 VR 场景设计参数。
> **原则**：编码必须人工完成，AI 不自动打标。本方案只提供维度、取值、判例与示例；所有字段在飞书 Base 中预留为空，等待人工逐条填写。
> **当前语料口径（2026-08-19 统一）**：高层主保留集 = **124 条**（飞书 Base「最终保留」表已核实 `records_count: 124`）；特殊保留集（B 类，低层/非住宅但弱势群体素材密度高）= **6 条**（存于 `_deleted_noise_backup.json`，不计入主集）；A 类 6 条纯噪声已永久删除。逐条编码结果直接写在 Base 的设计空间字段里，本文档是编码手册（codebook），不重复罗列 124 条原文。

## 一、标注目的与 Research Gap 对应（先捋清思路再打标）

核心问题：标注为了什么？每个标签要对应论文要填的 gap。以下把每个维度直接挂到 gap 上，确保 124 条编码出来能直接支撑论点。

| 编号 | Research Gap（论文要填的空） | 对应标注维度层 | 为什么 label 能填补该 gap | 老师优先级 |
|---|---|---|---|---|
| G0 | 现有火灾新闻以 2D 文本/视频呈现，读者是旁观者，难以具身理解"人如何被困、为何困住"，弱势群体处境被系统性忽视 | 全部维度（整体动机） | 把新闻转成可重建的 VR 设计参数，使 VR 补足 2D 缺失的具身共情 | — |
| **G1** | 沉浸式新闻多为旁观者/上帝视角，缺乏第一人称、身体化的叙事；叙事聚焦个体悲情多于系统性反思 | **Layer N 叙事层** | 标注每篇的叙事视角与聚焦对象，论证"现有新闻缺什么视角、VR 该补什么视角" | **① 叙事** |
| **G2** | 2D 新闻无法提供空间音频、触觉/温度、身体限制模拟、感知剥夺等具身反馈，这些是 VR 促共情的核心机制，却未被系统梳理 | **Layer E 交互促共情层** | 标注每条可用的共情机制与多模态反馈，直接映射"2D 没有、VR 独有"的设计空间 | **② 交互设计怎么促进共情（2D 新闻没有）** |
| **G3** | 弱势群体（老年/残障/儿童/孕妇/独居）在火灾中的具体处境困难（信息缺失、疏散不可达、看护责任、社会隔离）在新闻与 VR 设计中均被低估；需从"处境"而非仅"身体标签"角度标注 | **Layer V 少数人群处境层** | 不只标"谁是残障"，而是标"环境在哪一环断了他们的逃生路"，讲清弱势群体的结构性困境 | **③ 叙事角度共情少数人群处境** |
| G4 | 宏观建筑结构 ↔ 微观具身细节的跨尺度可视化缺失（"Visualizations Across Scales"线索） | 支撑层：空间层级 S1 / 感官主导 S2 | 标注微观户内细节与宏观立面/社区尺度，支撑跨尺度重建论点 | 支撑 |

> 标注时的自问：**这条新闻如果不做成 VR，2D 报道读者会漏掉什么？** 漏掉的那个点，就是它对应的 gap 与应打的标签。

## 二、编码原则

1. **判定单元**：单篇新闻报道的正文全文（以 Base 中"正文/摘要"为准）。
2. **证据优先**：每个取值必须能在正文中找到对应语句；不确定时留空或写备注。
3. **多选允许**：标注为"可多选"的字段，按正文实际出现的内容勾选；没有则不选。
4. **人工唯一**：AI 不得批量写入以下编码字段；可在备注里给出灵感，最终勾选由研究者完成。
5. **gap 对齐**：每条编码完成后，在备注里用 G0–G4 标注它主要服务于哪个 gap，便于后续统计。

## 三、Layer N · 叙事层（对应 G1，老师优先级①）

目标：刻画"这篇新闻是怎么讲这个火灾故事的"，为 VR 该采用什么叙事视角/结构提供证据。老师要求"更精细"——所以把原来混在一起的"视角"拆成**视角(N1) + 聚焦层级(N2) + 语气(N7)** 三块。

### N1 叙事视角（单选）

| 取值 | 定义 | 典型证据句 |
|---|---|---|
| 幸存者第一人称 | 正文以亲历者"我"的口吻描述逃生/被困 | "我听到火警铃时，周围全是浓烟" |
| 目击者/邻居 | 以旁观者身份描述他人遭遇 | "邻居破门而入，抱着婴儿冲出火场" |
| 救援者 | 消防员、急救人员或主动施救者的视角 | "我们破门后，发现老人倒在走廊" |
| 家属/亲友 | 亲属回忆、寻找、悼念 | "她打电话说楼道里全是烟，之后就联系不上了" |
| 官方/媒体全知 | 以媒体或官方通报口吻呈现全景 | "火灾造成 3 人死亡，14 人受伤" |
| 混合/多视角 | 同一报道中明显切换 2 种以上视角 | 先引用幸存者，再引用消防官员 |
| 系统性/追责视角 | 以调查、制度、责任归属为叙事主轴（如 Grenfell 式回顾） | "cladding 材料不合规导致火势竖向蔓延" |
| 拟人/动物视角 | 以宠物或其他非人主体承载叙事（较少见，作补充） | "被困的猫在窗台等待了三天" |

### N2 叙事聚焦层级（单选）

| 取值 | 定义 | 对 VR 重建的启示 |
|---|---|---|
| 个体（单人逃生） | 聚焦单一个体的逃生经历 | 适合单人身体替换 |
| 家庭/亲属连带 | 聚焦家庭成员间的救助、失联、悼念 | 适合亲密关联、道德选择 |
| 邻里/社区互助 | 聚焦邻居敲门、互助、集体疏散 | 适合 NPC 协作、社会见证 |
| 建筑/物业系统 | 聚焦楼宇设施、物业失职、结构缺陷 | 适合环境叙事、博物馆陈列 |
| 城市/政策系统 | 聚焦法规、普查、城市治理层面 | 适合系统性反思、跨案例对比 |

### N3 时间结构（单选）

| 取值 | 定义 | 典型证据 |
|---|---|---|
| 单点瞬间 | 只聚焦火灾爆发或某一关键动作 | 跳窗、爆炸、破门一瞬间 |
| 完整逃生序列 | 包含发现→反应→移动→获救/被困 | "闻到烟→跑下楼→被消防员接应" |
| 灾后回顾 | 以事件结果为前提进行倒叙 | 周年纪念、幸存者多年后的回忆 |
| 多时间线交织 | 同时呈现不同时间点 | 法庭陈述与现场描写交织 |
| 实时/进行式 | 带直播、滚动更新式的即时感 | "截至发稿，火势仍在蔓延" |

### N4 核心冲突（单选）

| 取值 | 定义 | 适合转化的 VR 张力 |
|---|---|---|
| 逃生 vs 被困 | 能否成功撤离是核心悬念 | 时间压力 + 路径选择 |
| 自救 vs 互救 | 救人还是保护自己 | 道德选择 |
| 信息缺失/警报延迟 | 警报失灵、信息不明确 | 感知剥夺（听障/视障） |
| 时间压力 | 火势快速蔓延 | 倒计时、火势可视化 |
| 建筑/设施缺陷 | 防火门、喷淋、疏散通道问题 | 环境叙事 + 事后反思 |
| 身体限制 vs 环境障碍 | 老年人/残障者无法使用楼梯 | 身体限制模拟 |
| 责任归属/追责 | 谁该为伤亡负责（开发商/物业/监管） | 系统性反思、批判叙事 |

### N5 情感弧线（单选）

| 取值 | 定义 | 示例 |
|---|---|---|
| 恐惧→绝望→获救 | 典型逃生叙事 | Palam 父女跳楼求生 |
| 恐慌→互助→平静 | 邻里互助型 | Skokie 邻居敲门示警 |
| 悲伤/哀悼 | 灾后纪念或死亡叙事 | 宏福苑幸存者回忆遇难邻居 |
| 愤怒/追责 | 法律、政策、建筑缺陷 | Grenfell 系统性回顾 |
| 温情/希望 | 救援成功、社区支援 | Bellevue 社区募捐 |
| 混合/复杂 | 以上多种情感并存 | 香港大埔系列报道 |

### N6 叙事颗粒度（单选）

| 取值 | 定义 | 对 VR 重建的启示 |
|---|---|---|
| 动作级 | 明确的人体动作（爬、跳、敲门） | 可直接做成交互点 |
| 场景级 | 详细的环境描写 | 适合做关卡美术与氛围 |
| 情绪级 | 大量心理/情感描写 | 适合做旁白、音效、UI |
| 数据级 | 以伤亡、损失数字为主 | 一般不适合直接重建，可作为背景板 |

### N7 叙事语气/立场（单选）

| 取值 | 定义 | 设计提示 |
|---|---|---|
| 悲情叙事 | 强调个体苦难、煽情 | 情感弧线偏悲伤/恐惧 |
| 英雄/救援叙事 | 突出消防员、见义勇为者 | 适合救援者角色 |
| 追责/批判叙事 | 指向系统性失职 | 对应 N4 责任归属 |
| 科普/预防叙事 | 教读者逃生知识 | 适合重复训练/纠错 |
| 中性通报 | 客观陈述事实 | 数据级为主 |

## 四、Layer E · 交互促共情层（对应 G2，老师优先级②，强调"2D 新闻没有"）

目标：刻画"VR 能用什么**独有**的具身机制让观众共情"。老师强调这是 2D 新闻做不到的，所以 E2 共情机制、E3 沉浸反馈做**最细**的拆分，明确哪些是 VR-only。

### E1 交互_身体化角色（多选）

| 取值 | 身体限制特征 | 典型交互映射 |
|---|---|---|
| 陈伯（老年） | 步速慢、体力耗尽、视力/听力下降 | 缓慢移动、体力条、放大声音/字幕 |
| 阿 May（听障） | 听不到警报、依赖视觉/振动 | 静音/低频、闪烁警报、手语 NPC |
| 罗姐（轮椅） | 无法使用楼梯、依赖电梯/救援 | 轮椅移动、坡道/电梯交互、等待救援 |
| 威廉（视障） | 低能见度、依赖听觉/触觉 | 高对比音频导航、触觉反馈 |
| King仔（儿童） | 身高低、认知有限、需被抱/牵 | 低视角、简化 UI、被抱起/牵手 |
| 阿福（拄拐） | 单腿/平衡差、步速受限 | 拄拐移动、扶手交互、跌倒风险 |
| 普通成年人 | 无显著限制 | 标准移动与交互 |
| 救援者 | 逆向进入、救人任务 | 携带装备、破门、背负 |
| 旁观者 | 不直接参与逃生 | 观察、记录、社会见证 |

### E2 交互_共情机制（多选，拆到子机制）

| 大类 | 细分取值 | VR-only? | 设计实现 |
|---|---|---|---|
| 感知剥夺 | 听觉剥夺（静音/低频警报） | ✅ 2D 无法"关掉声音" | 强制静音，仅留视觉/振动通道 |
| 感知剥夺 | 视觉剥夺（黑暗/浓烟遮蔽） | ✅ | 视野收窄、黑屏片段 |
| 感知剥夺 | 信息剥夺（警报失灵/指示缺失） | ✅ | 故意不给出逃生提示 |
| 身体限制模拟 | 移动限制（轮椅/拄拐/爬行） | ✅ | 受限移动、匍匐、无法上楼 |
| 身体限制模拟 | 感知限制（视障/听障） | ✅ | 模糊/黑暗、静音 |
| 身体限制模拟 | 认知/年龄限制（老年/儿童） | ⚠️ 部分 | 慢速、简化决策 |
| 时间压力 | 火势蔓延计时 | ⚠️ | 倒计时 UI、火势可视化 |
| 社会见证 | NPC 呼救、旁观他人伤亡 | ⚠️ | 旁侧音效、不可救的 NPC |
| 后果呈现 | 失败导致角色死亡/受伤 | ✅ | 不同选择→不同结局 |
| 道德选择 | 救人/自保、先救谁 | ✅ | 分支决策点 |
| 亲密关联 | 家人、宠物在场 | ⚠️ | 关联角色同步受险 |
| 代理感/能动性 | 玩家决策真实改变结果 | ✅ | 高 agency 交互，强化责任共情 |
| 空间具身 | 在真实尺度空间中身体在场 | ✅ | 1:1 空间、抬头看烟、俯身爬行 |

|---|---|---|---|

## 五、Layer V · 少数人群处境层（对应 G3，老师优先级③）

目标：老师最关注的第三点——**不要只贴"残障/老人"这种身体标签，而要标注"环境在哪一环断了他们的逃生路"**。这一层把"弱势群体"从"身体主体"升级为"处境分析"。

### V1 处境主体（多选，承载者是谁）

| 取值 | 与六角色对接 | 典型证据 |
|---|---|---|
| 老年人 | 陈伯 | "84 岁女子被送往医院" |
| 儿童 | King仔 | "8 岁男孩死亡""抱婴儿逃生" |
| 轮椅使用者 | 罗姐 | "坐轮椅的男子被困阳台" |
| 视障者 | 威廉 | "视障居民依靠导盲犬" |
| 听障者 | 阿 May | "听不到警报，靠邻居拍门" |
| 拄拐/助行器 | 阿福 | "elderly person with a walker" |
| 孕妇/抱婴者 | — | "pregnant woman trapped" |
| 独居者 | — | "独居老人，数日后才被发现" |
| 低收入住户 | — | "违建分隔、消防设施缺失" |
| 宠物 | — | 救猫/救狗、宠物死亡 |

### 12.0 总览：7 维 + 两遍标注法

**第一遍 · 新闻故事标注（5 维）** —— 回答「这篇新闻怎么讲这个故事」
- ① 视角（语法人称）
- ② 叙事视角（内容立场）
- ③ 叙事结构（时间线）
- ④ VR 可模拟性（新闻→VR 的桥，只标可重建片段）
- ⑤ 情感标签（固定六类）

**第二遍 · VR 设计标注（E1 + 2 机制）** —— 回答「VR 该用什么手段制造共情」
- E1 身体主体（人物是谁）
- 机制一 · 氛围叙事（信息呈现 / 多模态感知剥夺 / 环境模拟 / V_framing）
- 机制二 · 交互（E3交互 / E5 / E6 / 限制模拟 / V处境困难）

### 12.1 第一遍 · 新闻故事标注

#### ① 视角（单选，语法层面的人称）
| 取值 | 判定 | 典型证据 |
|---|---|---|
| 第一人称 | 正文出现亲历者「我/我们」口吻 | "我听到警报时，周围全是浓烟" |
| 第三人称 | 记者/媒体转述，无「我」 | 绝大多数新闻报道 |
| 混合 | 同时含第一人称引语与第三人称叙述 | 引语 + 报道主体 |

#### ② 叙事视角（单选，内容层面的叙事立场；原 E4 并入）
| 取值 | 定义 | 典型证据 |
|---|---|---|
| 幸存者第一人称 | 亲历者「我」描述逃生/被困 | "我爬过浓烟的楼梯才逃出来" |
| 目击者/邻居 | 旁观者描述他人遭遇 | "邻居破门而入，抱着婴儿冲出" |
| 救援者 | 消防员/施救者视角 | "我们破门后，发现老人倒在走廊" |
| 家属/亲友 | 亲属回忆、寻找、悼念 | "她打电话说楼道里全是烟，之后失联" |
| 官方/媒体全知 | 媒体或官方通报口吻呈现全景 | "火灾造成 3 死 14 伤" |
| 混合/多视角 | 同一报道明显切换 2 种以上视角 | 先引幸存者，再引消防官员 |

#### ③ 叙事结构（单选）— 锁定 1-A 粒度：只标时间结构
| 取值 | 判定 |
|---|---|
| 线性 | 按时间顺序单线推进（多数新闻）|
| 倒叙 | 以结果/纪念为前提回望（灾后回顾、周年、纪念墙）|
| 多线 | ≥3 个独立空间/群体并行叙述 |

> **为什么砍掉因果维度**：因果链（为什么起火、导致什么后果）对 VR 设计而言落在 ④ VR可模拟性（哪些因果能变成可交互冲突），独立标易与 ④/核心冲突重复，徒增负担。若某条因果特别关键且非空间冲突，在 ④ 文本里写明即可。如需 B 方案（时间+因果+冲突三块），在备注标注 `[结构B]`。

#### ④ VR 可模拟性（文本）— 新闻→VR 的桥
定义：只摘录正文中**能用 VR 制造冲突感/临场感**的片段；不写全篇摘要，不写与 VR 无关的背景。
写法模板：`空间：…；冲突：…；交互：…`
例：`空间：疏散通道被杂物堵死、消火栓被遮挡；冲突：防火门闭门器损坏无法闭合；交互：推门受阻、匍匐绕行`

#### ⑤ 情感标签（单选）— 锁定 2-A 六类
| 取值 | 典型情境 |
|---|---|
| 恐惧 | 火势逼近、被困、跳楼求生 |
| 悲伤 | 死亡、悼念、纪念墙 |
| 愤怒 | 失职、追责、门锁困人 |
| 无助 | 信息缺失、设备失效、无法自救 |
| 希望 | 成功救援、互助、社区支援 |
| 其他 | 中性通报/数据为主 |

> 多情感并存时取**主导**情感；若并列明显，选「其他」并在备注写并列项（如 `恐惧+无助`）。

### 12.4 边缘情况裁决
- **纪念墙/纪念馆类**（如 7165）：叙事结构=倒叙，情感=悲伤，交互机制=V处境困难，④ 注明「纪念馆式，非主动逃生」；是否入主保留集由人工定，可单列 memorial 子集。
- **低层/非住宅但弱势群体密度高**：保留但备注「非高层」，④ 聚焦弱势处境而非建筑高度。
- **混合视角/多空间**：按 12.3 规则取主导或标混合/多线，备注说明。
- **旧字段为空**：AI 据 `正文/摘要` 判，标注 `[AI初标-据正文]`。
