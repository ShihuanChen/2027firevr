# 设计空间六轴 · 定义卡 v2.3（供 AI 打标使用）

用途：与 `提示词_v3_四组.md` 配套。凡提示词中的轴名、取值代码，一律以本卡为准。
锚例全部取自本项目语料与 2026-10 补搜，**不得替换为外部知识**。

---

## 使用规则（四条，先读）

1. **只依据给定正文判定。** 正文没写的，填 `未报告`，不推断、不补全。
2. **每轴可多选，但要标主次。** 一条新闻常同时出现多种情况（老人 + 轮椅 + 被锁门）。输出格式为 `[取值1, 取值2]`，第一个是主主体处境。
3. **必须附证据句。** 每个非 `未报告` 取值配一句正文逐字摘录（≤30 字）。摘不出就退为 `未报告`。
4. **允许判"装不进"。** 若某段内容确实无法归入任何取值，填 `off_axis: "有"` 并在 `off_axis_note` 里写清是什么。**这一项是本次验证的核心指标，不要为了填满而强行归类。**

## A 轴 · 信息可达性

> 当事人当时能否获得"着火了"这个判断，以及靠什么获得。

| 取值 | 判定线 | 锚例（本项目语料） |
|---|---|---|
| A1 全通道冗余 | 至少两条独立通道同时有效（警报 + 广播 + 邻居敲门 + 可见烟） | 马德里 Torre Moeve：警报先响，广播明确"真实火灾立即撤离"，喷淋正常动作 |
| A2 单通道 | 只有一条通道有效，其余失效或不存在 | 宏福苑 Wing Wu：没有警报，先闻到烟→走廊涌入→fire 喊声与敲门 |
| A3 物理屏蔽 | 构件挡住视线或阻断感知（泡棉封窗、施工围挡、无窗走廊、门缝封死） | 宏福苑 78 岁刘宇洪：泡棉封窗致看不见烟，靠浴室窗偶然看到隔壁楼火 |
| A4 经验错位 | 有信号但被当事人按日常经验解释成无害 | 宏福苑 3 楼谢玉华：闻到烟，以为是装修灰尘，由管理 staff 敲门才知 |
| A5 完全无信息 | 没有任何可用于判定"是否着火"的信号；闻到异味但查不出源、警报不响、无人告知 | 迪拜 Marina Pinnacle：24 楼闻到烧电线味，查完厨房无果，无警报无官方通知 |

**易混**：A3 是"感知被挡"，A4 是"感知到了但解释错"，A5 是"没有可用感知"。三者可同时成立，按主次排序。

## B 轴 · 确认的社会性

> "着火了"这件事，最后由谁完成确认。

| 取值 | 判定线 | 锚例 |
|---|---|---|
| B1 自主确认 | 当事人靠自己的感官或亲自行动完成确认，无他人介入 | 宏福苑 Ng：警报没响她不确定，出于好奇下楼，亲眼确认后才信 |
| B2 他人之口 | 由具体某个他人（邻居、朋友、家人、保安）告知 | 宏福苑 Wing Wu 由邻居敲门；迪拜 28 楼靠来访朋友电话才知道 |
| B3 社群数字 | 通过群聊、门铃摄像头、社交平台等中介化渠道获知 | 宏福苑：智能门铃画面全白、走廊三人聚集查后楼梯、按火警但无声 |
| B4 官方广播 | 由建筑广播、警报系统、官方通知统一发布 | 马德里：警报 + 广播明确要求立即撤离 |
| B5 无人确认 | 无人告知、无警报、无人敲门，当事人始终未获正式确认 | 宏福苑刘宇洪原话 "Nobody warned us. No alarm went off. We escaped by ourselves." |

**预登记候选档（v2.3 不启用，仅在 off_axis 中提及）**：`B6 身体换取`——没有信号，当事人必须亲自动身（下楼、开门、走到走廊）才能换来一次确认，确认的代价是暴露于烟气。宏福苑 Ng 与迪拜 24 楼两例都落在这里，但现有 B1 无法区分"有信号下的自主确认"与"无信号下的以身换信息"。**若 off_axis 中此类反复出现，v2.4 增设此档。**

## C 轴 · 可行动集

> 当事人当时实际能走的路径还有哪些。

| 取值 | 判定线 | 锚例 |
|---|---|---|
| C1 全通道可用 | 楼梯、出口、避难层均可用，无阻断 | 马德里：楼梯有序下行，3 人进入 27 层避难区 |
| C2 单一通道 | 只有一条路径，且通行能力受限（宽度、容量） | 广州 9/10 层：楼梯仅容单人；海得拉巴：唯一楼梯仅 1 米宽 |
| C3 通道在但身体不配 | 路径物理上存在，当事人身体条件不足以使用 | Marion Towers：轮椅老人在室内无反应；新加坡 Chai Chee：轮椅 + 氧气瓶，需警察背下 9 层 |
| C4 通道在但被锁 | 路径存在但被上锁、铁链、堆物、工程封闭 | 约翰内斯堡 Usindiso 主逃生门铁链锁死；科威特 Mangaf 天台门锁死；肇庆铁锁反锁、拿不到钥匙 |
| C5 通道本身致命 | 路径已被烟充满或成为烟囱，走进去等于进入危险 | 迪拜：楼梯间全是烟，只能乘电梯；海得拉巴：唯一楼梯充烟 |
| C6 通道归零 | 所有路径同时不可用，只剩跳楼、悬空等极端选择 | 德里 Dwarka：电子锁锁死、门厚 40–41cm、破拆失败，父女三人退至阳台后跳下 |

**易混**：C4 是"被外力锁住"，C3 是"门开着但身体过不去"，C5 是"路在但走进去会死"，C6 是前几类同时发生导致路径总数为零。

## D 轴 · 决策指向

> 当事人最终把身体投向哪个方向。

| 取值 | 判定线 | 锚例 |
|---|---|---|
| D1 向下撤离 | 走楼梯或电梯向下离开建筑 | 马德里；宏福苑 Ko 见烟后乘电梯逃生 |
| D2 向上 | 向上走、上天台、上避难层 | 科威特 Mangaf：上层工人试图上天台（门锁死）；马德里 3 人上 27 层避难区 |
| D3 就地固守 | 留在房间内、关门堵缝、等待救援 | 厦门湖里：119 指导关门、湿毛巾堵门缝；宏福苑李威廉：湿毛巾堵门缝、带 60 多岁夫妇回家 |
| D4 横向转移 | 跨户、跨楼、跨阳台移动 | 安特卫普 8 楼：爬外墙进入邻居窗 |
| D5 极端退出 | 跳楼、悬于窗外、攀爬外立面等非常规离楼 | 德里 Dwarka 跳楼；广州女主人悬在 9 楼空调外机 |

## E 轴 · 能动性来源

> 谁来拿走或交还当事人的行动决定权。

| 取值 | 判定线 | 锚例 |
|---|---|---|
| E1 自主 | 当事人自行判断并自行决定 | 宏福苑 Ng：没人通知，自己决定下楼看 |
| E2 被他人说服 | 行动由他人劝说、带领、搀扶促成 | 宏福苑李威廉带 60 多岁夫妇回家；安特卫普邻居劝说撤离 |
| E3 被信息替代 | 判断被外部指令替代（接警员、调度、远程指导） | 厦门湖里：119 接警员全程电话指导关门堵缝、捂口鼻 |
| E4 被制度延迟 | 当事人在等通知、等警报、等指令，行动被制度时序拖住 | 迪拜 28 楼：一小时后朋友短信才知道；宏福苑 Ng：等警报→没响→不确定→拖到好奇才动 |
| E5 被制度否定 | 官方信号或指令本身使当事人做出错误判断（被告知没事、警报被关闭） | 宏福苑听证会：8 座中 7 座火警被关闭；专家访谈 Haghani 指 "stay calm, wait for instructions" 经实证有害 |

**关键区分**：E4 是"没等到"，E5 是"等到了错的"。两者都指向制度，但设计介入点不同。

## F 轴 · 处境主体

> 谁的处境被这篇报道呈现。

| 取值 | 判定线 | 锚例 |
|---|---|---|
| F1 普通成人 | 无特殊身体或社会条件限制 | 迪拜 24 楼住户、宏福苑 Ko |
| F2 老年 | 报道明确写年龄或"elderly" | 宏福苑 78 岁刘宇洪；Marion Towers 轮椅老人 |
| F3 儿童 | 未成年，含婴幼儿 | 德里 Dwarka 两名 10 岁儿童；海得拉巴 8 名儿童 |
| F4 轮椅／行动不便 | 依赖轮椅、助行器、卧床 | 新加坡 Chai Chee 轮椅 + 氧气瓶；Marion Towers |
| F5 视障 | 明确视力障碍 | （现有语料未出现，留空档） |
| F6 听障 | 明确听力障碍，或依赖视觉警报 | （现有语料未出现，留空档） |
| F7 孕妇／抱婴 | 孕期或怀抱婴幼儿 | 宏福苑报道提及抱婴撤离 |
| F8 独居 | 报道明确独居、无人可求助 | 宏福苑刘宇洪（78 岁，独自在家） |

**规则**：F5、F6 目前为零，是设计空间的真实空单元，不要为了填满而误标。

## 与 `Design Space (1).md` 的关系（一句话）

md 是标注维度表，回答"这条新闻写了什么、能不能在头显里重建"；六轴是坐标系，回答"这个场景落在设计空间哪一格"。**两层并存，md 一项不砍，六轴一轴不减。**
